mysolenso.const — Constants

Configuration constants for the MySolenso library.

This module centralises all fixed values used by the library: base URLs, API endpoints, and network parameters. Modifying this file is sufficient to point the library at a different environment (e.g. staging).

Two base URLs are used:

  • BASE_URL_SOLENSO — the Solenso monitoring platform (authentication, user profile, station list, station detail, energy counters).

  • BASE_URL_HOYMILES — the Hoymiles inverter data API (intra-day power curve, day-of-year production totals).

mysolenso.const.BASE_URL_SOLENSO: str = 'https://monitor.solenso.net/platform/'

Root URL of the Solenso monitoring platform.

mysolenso.const.BASE_URL_HOYMILES: str = 'https://neapi.hoymiles.com/pvm-data/api/'

Root URL of the Hoymiles inverter data API (used for power/energy history).

mysolenso.const.API_AUTH_LOGIN: str = 'https://monitor.solenso.net/platform/api/gateway/iam/auth_login'

POST endpoint for credential-based authentication.

Expects a JSON payload with user_name and password; returns a session token on success.

mysolenso.const.API_USER_ME: str = 'https://monitor.solenso.net/platform/api/gateway/iam/fun_api_1_user_me'

POST endpoint for the connected user’s account information.

Returns name, email, role, and group details for the authenticated user.

mysolenso.const.API_STATION_ME: str = 'https://monitor.solenso.net/platform/api/gateway/pvm/station_select_by_page'

POST endpoint for paginated retrieval of the user’s PV stations.

Returns a response with total (int) and list (array of station dicts).

mysolenso.const.API_STATION_FIND: str = 'https://monitor.solenso.net/platform/api/gateway/pvm/station_find'

POST endpoint to retrieve the full detail record of a single PV station.

Expects {"id": <station_id>} in the request body.

mysolenso.const.API_STATION_COUNT: str = 'https://monitor.solenso.net/platform/api/gateway/pvm-data/data_count_station_real_data'

POST endpoint for real-time and cumulative energy counters of a station.

Returns today’s yield, monthly/yearly/lifetime totals, current power, CO₂ savings, equivalent trees planted, and data timestamps.

mysolenso.const.API_POWER_BY_DAY: str = 'https://neapi.hoymiles.com/pvm-data/api/0/station/data/count_power_by_day'

POST endpoint for the intra-day grid power curve of a station.

Expects {"sid": <station_id>, "date": "YYYY-MM-DD"}; returns a binary protobuf response with HH:MM time labels and packed float32 power values.

mysolenso.const.API_POWER_DAY_OF_YEAR: str = 'https://neapi.hoymiles.com/pvm-data/api/0/station/data/count_eq_by_day_of_year'

POST endpoint for day-of-year energy production totals.

Expects {"sid": <station_id>}; returns a mixed text/binary protobuf response with YYYY-MM-DD date strings and packed float32 Wh values covering every day since the station was commissioned.
