mysolenso.const — Constants

Configuration constants for the MySolenso library.

This module centralises all fixed values used by the library: base URL, API endpoints, and network parameters. Modifying this file is sufficient to point the library at a different environment (e.g. staging).

mysolenso.const.DEFAULT_TIMEOUT

Network timeout in seconds applied to every HTTP request. Defaults to 10.

Type:

int

mysolenso.const.BASE_URL_SOLENSO

Root URL of the Solenso platform. All API routes are built from this base.

Type:

str

mysolenso.const.API_AUTH_LOGIN

Authentication endpoint. Expects a JSON payload containing user_name and password, and returns a session token.

Type:

str

mysolenso.const.API_USER_ME

Authenticated user profile endpoint. Returns account information (name, email, role, group…).

Type:

str

mysolenso.const.API_STATION_ME

User PV station list endpoint. Returns a paginated response with total and list.

Type:

str

Example

Direct use of constants (internal usage):

from mysolenso.const import API_AUTH_LOGIN, DEFAULT_TIMEOUT
response = session.post(API_AUTH_LOGIN, json=payload, timeout=DEFAULT_TIMEOUT)
